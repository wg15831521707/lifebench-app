更新内容（v1.5.25）

  • 修复抖音热榜刷新失败：远端 label 为数字导致整批 JSON 解析异常、刷新被中止、永远回退缓存；现统一归一化为「热/沸/新」字符串。
  • 热榜实时更新：代理迁至阿里云函数计算 FC（默认域名 *.fcapp.run 国内直连，彻底绕过 Cloudflare DNS 污染），下拉刷新即拉取最新热榜。
  • 刷新交互：下拉刷新 / 顶栏刷新按钮，进页面静默刷新，时间戳行显示最近更新时间与条数；失败时 Toast 显示具体原因。
  • 离线兜底：网络失败时自动回退本地缓存数据并 Toast 提示，弱网环境也能正常浏览。
